# 원재료 근거 출처 정책

## 원칙

원재료 라벨은 사실 전사와 안전 판정을 분리합니다. OCR·언어 모델·판매처 설명은 이름과 표기 후보를 찾는 데만 사용하며 위험도, 알레르기, 효능, 점수를 설정할 수 없습니다. 활성 원료와 분석 규칙에는 검토된 근거 ID가 반드시 있어야 합니다.

## 출처 우선순위

1. 적용 법령·행정규칙과 정부 규제기관 자료
2. 수의과 대학·수의학 전문 참고자료와 원 연구 논문
3. 공식 표준기관의 명칭·표시 지침
4. 제조사 공식 라벨은 해당 제품의 구성 사실에만 사용
5. 판매처·블로그·검색 결과는 발견용으로만 사용

규정상 허용된 원료라는 사실은 개별 반려동물에게 안전하거나 적합하다는 뜻이 아닙니다. 명칭 근거와 독성·알레르기 근거는 별도 주장으로 저장합니다.

## 저장 필드와 검토

출처에는 ID, 기관, 제목, URL, 유형, 관할, 접근일, 허용 용도를 저장합니다. 주장에는 대상 종, 주장 유형, 400자 이하 요약, 원문 위치, 검토자와 검토일을 저장합니다. 저작권이 있는 정의나 표 전체를 복제하지 않고 짧은 사실 요약과 링크만 보관합니다.

활성화 전 확인 사항:

- 표준 이름과 원천 가족·부위·가공형태가 구분되어 있는가
- 별칭이 다른 활성 원료와 충돌하지 않는가
- 근거의 허용 용도가 해당 주장과 일치하는가
- 독성·알레르기 주장은 종과 가공형태 조건을 포함하는가
- 검토 메모와 변경 영향 제품 수가 기록되는가

## 갱신과 라이선스

접근일과 URL 상태를 정기 점검합니다. 출처의 이용조건이 본문 재배포를 허용하지 않으면 사실 요약과 인용 위치만 저장합니다. 출처가 철회되거나 규정이 바뀌면 관련 규칙을 비활성화하고 영향 제품만 재분석합니다.
