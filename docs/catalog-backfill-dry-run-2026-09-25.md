## 발견된 품질 문제

- `광동 견옥츄 덴탈껌 12g x 15개입`이 `광동 견옥츄 덴탈껌 12g x`로 끝나는 사례가 있다.
- `안먹으면 100% 환불 보장` 같은 판매 문구가 표시명에 남는 사례가 있다.
- 사료·간식·영양제가 아닌 것으로 보이는 상품이 기존 수집 데이터에 섞였을 가능성이 있다.
- 브랜드 첫 단어 추정은 유용하지만 공식 브랜드 확인 전에는 근거 등급이 낮다.

따라서 이 보고서는 후보 산출 검증 자료이며, 자동 적용 승인 자료가 아니다.

## 적용 안전장치

`scripts/apply-catalog-backfill.mjs`는 다음 조건을 모두 만족할 때만 제품 단위 RPC를 호출한다.

1. 드라이런 JSON의 실제 소문자 SHA-256와 `--confirm` 값이 정확히 일치한다.
2. `needsReview`가 아니며 슬러그·정규키 충돌 그룹에 포함되지 않는다.
3. 운영의 원문 제품명, 기존 브랜드, `last_observed_at`이 드라이런 스냅샷과 같다.
4. `display_name`, 정규화 필드, 정규 제품키, 슬러그가 아직 비어 있다.
5. 원문 제품명 `products.name`은 수정하지 않고 검색 가능한 `source_title` 별칭으로 보존한다.
6. 제품 갱신과 별칭 저장은 한 데이터베이스 트랜잭션에서 처리한다.
7. 결과는 `.artifacts/catalog-backfill-apply.jsonl`에 추가 전용으로 기록한다.

실제 적용은 다음 조건이 갖춰질 때 별도 실행한다.

- 카탈로그 기반 스키마와 `apply_catalog_backfill_candidate` RPC가 운영에 배포됨
- 위 품질 이상 규칙이 보완되고 후보가 다시 검토됨
- 서비스 역할 자격 증명이 안전한 실행 환경에 제공됨
- 운영 쓰기에 대한 명시적 승인이 있음
